# آمادگی تحویل — فاز ۲

این سند وضعیت واقعی تحویل فاز دو را ثبت می‌کند. اجرای بیست Prompt به‌تنهایی «آماده Production» نیست و اینجا هم چنین ادعایی نمی‌شود. آمادگی فاز یک در [release-readiness.md](release-readiness.md) است و این سند جایگزینش نیست، مکملش است.

تاریخ: ۲۰۲۶-۰۹-۱۲ · پایه: PROMPT-019 (`274a339`)

## ۱. نقطه شروع

```bash
npm ci && docker compose up -d && npm run db:migrate && npm run db:seed
npm run build && npm run start        # http://127.0.0.1:3000
```

بررسی سلامت: `GET /api/health` · Runbook: [runbook.md](runbook.md) · راهنمای اپراتور: [operator-guide.md](operator-guide.md) · ماتریس کیفیت: [phase-2-acceptance.md](../qa/phase-2-acceptance.md).

## ۳. آنچه هنوز داده واقعی می‌خواهد

از ۴۴ کلید تنظیمات، **۱۳ کلید عمداً بدون مقدار** شروع می‌کنند. تا واردکردن مقدار واقعی، همان قابلیت بسته می‌ماند و هیچ عددی حدس زده نمی‌شود:

| گروه | کلیدها | چه کسی باید تأمین کند |
|---|---|---|
| مرکز ژنتیک | `genetics_centre.payment_card` | انجمن یا مرکز؛ هیچ مقصد مالی ساختگی وارد نشده |
| یکپارچه‌سازی | `integration.sms.provider`، `integration.sms.api_key`، `integration.payment.provider`، `integration.payment.api_key`، `integration.map.api_key`، `integration.map.embed_url_template` | تأمین‌کننده‌ها. تا ثبت قالب embed نقشه، هیچ نقشه‌ای رندر نمی‌شود (DEC-0175) |
| تبلیغات | شش قیمت بسته ویژه و حرفه‌ای در سه بازه | مالک محصول. هیچ بسته‌ای بدون قیمت واقعی فروخته نمی‌شود (P2-D03) |

همچنان خالی و عمدی: فهرست صادرکنندگان شجره‌نامه، دامپزشکان و مراکز از پیش تأییدشده، و هر محتوای منتشرشده. این‌ها کار عملیاتی‌اند، نه کمبود کد.

## ۴. Known Gaps فاز ۲

۱۳۴ محدودیت در گزارش‌های `docs/reports/phase-2/PROMPT-0NN.json` ثبت شده است. بخش بزرگی از آن‌ها را پرامپت بعدی همان مسیر بسته است (مثلاً «جست‌وجوی ایندکس‌شده با ۰۱۲» یا «ادغام رکورد با ۰۱۶»). آنچه در لحظه تحویل **باز** است:

| موضوع | وضعیت |
|---|---|
| وفاداری بصری فاز ۲ | **UNVERIFIED**؛ هیچ فریم Figma برای سطح عمومی فاز دو در منابع نیست و تطبیق پیکسلی ادعا نشد |
| مهاجرت معکوس (`down`) | وجود ندارد؛ بازگشت بر ثابتِ افزایشی‌بودن تکیه دارد که تست می‌شود (DEC-0179). مسیر امن بازگشت داده، Snapshot است |
| جست‌وجوی سراسری | فدراسیون شش منبع در حافظه است؛ ایندکس واقعی تغییر پایگاه‌داده جداگانه می‌خواهد (DEC-0172) |
| خروجی انبوه (Export) | ساخته نشد؛ هر خواندن عملیاتی صفحه‌بندی و محدود است (DEC-0177) |
| Core Web Vitals | اندازه‌گیری میدانی انجام نشد؛ فقط علت‌های ساختاری حذف شد (DEC-0178) |
| صفحه‌خوان واقعی | اجرا نشد؛ ساختار معنایی و مسیر صفحه‌کلید تست شده است |
| وضعیت «باطل» سند | منبعی در فاز یک ندارد؛ فقط `REPLACED` از یادداشت اصلاح می‌آید (DEC-0174) |
| تصویر مراکز و انجمن‌ها | خط لوله تصویر عمومی فقط محتوا را سرو می‌کند (DEC-0160) |
| ناپایداری تست آپلود تصویر محتوا | `tests/browser/content.test.ts` در دو اجرای کامل روی گام آپلود timeout داد و در دو اجرای دیگر (کامل و تنها) سبز شد. علت اثبات نشده؛ پیام شکست اصلاح شد تا دفعه بعد متن واقعی بنر را بگوید |
| آسیب‌پذیری `postcss` از زنجیره `next` | از فاز یک باز است؛ رفع رسمی ارتقای major است و در مسیر درخواست کاربر اجرا نمی‌شود |
