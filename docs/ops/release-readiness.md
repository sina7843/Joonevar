# آمادگی تحویل — فاز ۱

این سند وضعیت واقعی تحویل را ثبت می‌کند: چه چیزی ساخته و بررسی شده، چه چیزی هنوز داده یا اعتبارنامه واقعی می‌خواهد، و چه چیزی اصلاً در دامنه این فاز نبوده است. اجرای بیست Prompt به‌تنهایی «آماده Production» نیست و اینجا هم چنین ادعایی نمی‌شود.

## ۱. نقطه شروع

```bash
npm ci && docker compose up -d && npm run db:migrate && npm run db:seed
npm run build && npm run start        # http://127.0.0.1:3000
```

بررسی سلامت: `GET /api/health`. راهنمای کامل: [runbook.md](runbook.md) · راهنمای اپراتور: [operator-guide.md](operator-guide.md) · گزارش کیفیت: [phase-1-acceptance.md](../qa/phase-1-acceptance.md).

## ۲. آنچه واقعاً اجرا و دیده شد

| بررسی | فرمان | نتیجه |
|---|---|---|
| نصب از Checkout تمیز | `git clone` → `npm ci` | ۶۳ بسته نصب شد |
| Typecheck | `npx tsc --noEmit` | exit 0 |
| ساخت production | `npm run build` | موفق، همه مسیرها کامپایل شدند |
| اجرا و Smoke | `npx next start` → `/login` و `/api/health` | ۲۰۰ · وضعیت `degraded` با نام‌بردن دقیق مقادیر تعیین‌نشده |
| Migration روی دیتابیس تمیز و دوباره | `npm run db:migrate` | ۱۵ migration اعمال شد؛ اجرای دوم چیزی replay نکرد |
| پشتیبان‌گیری و بازگرداندن | `tests/db/backup-restore.test.ts` | Snapshot گرفته شد، schema و فایل‌ها واقعاً حذف شدند، بازگرداندن انجام شد و پیوند نمونه/سند/فایل خصوصی سالم ماند |
| تست دامنه و دیتابیس | `npm test` | ۳۳۱/۳۳۱ |
| تست مرورگر | `npm run test:browser` | ۸۸/۸۸ |
| اعتبارسنجی بسته | `node tools/validate-core.mjs` | معتبر |

## ۳. آنچه هنوز داده یا اعتبارنامه واقعی می‌خواهد

| مورد | وضعیت | چه کسی باید تأمین کند |
|---|---|---|
| تعرفه‌های واقعی (برگه ثبتی، شجره‌نامه، مجوز، کنل، کارت توله) | تعیین‌نشده | انجمن. تا آن زمان مسیر پرداخت همان قلم بسته می‌ماند |
| مشخصات، حساب و کارت مرکز ژنتیک | تعیین‌نشده | انجمن/مرکز |
| Provider پیامک | پیکربندی‌نشده | تأمین‌کننده؛ نیازمند شاهد sandbox سپس live |
| درگاه پرداخت | پیکربندی‌نشده | تأمین‌کننده؛ نیازمند شاهد sandbox سپس live |
| Provider نقشه (MAP-001) | پیکربندی‌نشده | باز از فاز طراحی |
| قالب رسمی چاپ سند | پیکربندی‌نشده | انجمن |
| ریدر میکروچیپ | سخت‌افزار در دسترس نیست | ورود دستی همیشه کار می‌کند |
| تصویر مرجع پروتوتایپ برای تطبیق بصری | در دسترس نیست | طراحی؛ تا آن زمان وفاداری بصری UNVERIFIED است |
| فهرست واقعی صادرکنندگان شجره‌نامه | خالی | انجمن، از `/assoc/issuers` |
| داده دامپزشکان و مراکز از پیش تأییدشده | خالی | انجمن/سوپرادمین، از `/admin/vets` |

هیچ‌کدام از این موارد با مقدار ساختگی پر نشده است.

## ۴. ریسک‌های شناخته‌شده

| ریسک | شدت | وضعیت |
|---|---|---|
| آسیب‌پذیری `postcss` از زنجیره `next` | high (زمان build) | باز؛ رفع رسمی، ارتقای major به Next 16 است. در مسیر درخواست کاربر اجرا نمی‌شود |
| نبود تطبیق بصری با پروتوتایپ | متوسط | باز؛ Gate تا رسیدن تصویر مرجع باز می‌ماند |
| نبود شاهد sandbox/live برای پرداخت و پیامک | بالا برای راه‌اندازی | باز؛ روال آن در runbook §۴ آمده است |
| بازگشت migration | متوسط | migration معکوس خودکار وجود ندارد؛ مسیر امن، بازگرداندن Snapshot است |
| MAP-001، INC-01، INC-02 | تاریخی | همچنان باز؛ با اجرای این بسته بسته نشده‌اند |
