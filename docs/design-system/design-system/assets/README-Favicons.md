# Favicons

One favicon for every app-icon option: the full-colour symbol, pixel-fitted at each size (body 14 / 28 / 42 px) on a transparent ground — both cut-outs stay legible at 16px, unlike the single-ink silhouettes tested (see *Brand*). Files: `favicon.svg` (modern browsers), `favicon-16.png`, `favicon-32.png`, `favicon-48.png`. A multi-size `favicon.ico` (16/32/48) is part of the brand file package delivered outside this system (the asset store does not hold .ico files).
