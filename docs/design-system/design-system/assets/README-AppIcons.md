# App icons (PWA)

Three options built from the same symbol, centred on its smallest enclosing circle so it survives the maskable safe zone (central 80%), the iOS squircle and the Android circle. All PNGs are opaque, square-cornered, rendered from `icon.svg`.

- **A — chosen (11 Mehr 1405)**: orange symbol on `bg-chrome` cream (3.22:1). Matches the app chrome and the splash colour; continues today's cream icon.
- **B**: cream symbol on orange — strongest on a busy home screen.
- **C**: orange symbol on ink — a dark tile.

Per option (`A/`, `B/`, `C/`): `icon.svg` (source), `icon-1024.png`, `apple-touch-icon-180.png`, `pwa-192.png`, `pwa-512.png`, `pwa-maskable-512.png`. Manifest colours for every option: `theme_color` and `background_color` = cream-50 (`bg-chrome`). Shown on iPhone and Android home screens and in a browser tab on the canvas board *B02*.
