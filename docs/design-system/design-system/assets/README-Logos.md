# Logos

The fixed Hamzist mark and its lockups (rules in *Brand*). Symbol paths and the Persian wordmark are the approved geometry; the English wordmark «Hamzist» is IRANSansX Black outlined at the same size. Clear space 1X = the radius of the circle cut-out; minimums: symbol 24px (32 recommended), horizontal lockup 26px tall (30 recommended, 36 in the site header), stacked lockup 96px wide.

- `hamzist-lockup-fa-horizontal.svg`, `hamzist-symbol.svg` — the two files approved at checkpoint 1 (identical artwork to `lockup-horizontal-fa-light.svg` and `symbol.svg`).
- `symbol.svg` — symbol alone: favicon source, OpsShell rail, missing-image placeholder (40% opacity), avatars.
- `lockup-horizontal-fa-light.svg` — the default, in every shell header and the A4 document head. In RTL the symbol is at the start (right). Inks: wordmark `logo-ink`, mark `logo-mark`, cut-outs `logo-cutout`.
- `lockup-horizontal-fa-dark.svg` — for dark grounds (future dark theme, dark photo plates): wordmark in `logo-cutout` cream.
- `lockup-horizontal-fa-mono-ink.svg` / `-mono-orange.svg` / `-mono-white.svg` — one ink each (cut-outs become holes): print, seal, document watermark (mono-ink, 6% opacity, print and export only).
- `lockup-stacked-fa-{light,dark,mono-ink}.svg` — centred square spaces only (sign-in card head, certificate cover); never in chrome bars.
- `lockup-horizontal-en-{light,dark,mono-ink}.svg`, `lockup-stacked-en-{light,dark}.svg` — English/LTR only (future); symbol at the start (left), never mirrored.

Never stretch, rotate, recolour, add shadows, place on a busy photo without a solid plate, or swap symbol and wordmark order.
