  2. ۲کلینیک دامپزشکی آواکلینیک دامپزشکی، تهرانشنبه تا چهارشنبه ۹ تا ۲۱معتبر
  3. ۳مرکز ژنتیک همزیستمرکز ژنتیک، تهرانشنبه تا چهارشنبه ۹ تا ۲۱معتبر
