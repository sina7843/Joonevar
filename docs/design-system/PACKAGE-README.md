# همزیست: تحویل سیستم طراحی به تیم توسعه

نسخه **v1.0.4** · تأیید نهایی: ۱۱ مهر ۱۴۰۵ · صفحه خانه: ۲۲ مهر ۱۴۰۵ · بسته تحویل: ۲۳ مهر ۱۴۰۵

این فایل همه چیزِ لازم برای پیاده‌سازی سیستم طراحی در اپ با Claude Code را دارد: قاعده‌ها، فونت، لوگو، عکس‌ها، تصویر و کد مرجع صفحه‌ها، داده نمایشی و QA نهایی.

## مراحل کار تیم توسعه

1. **کپی در ریپو:** محتوای پوشه `hamzist-design-system-v1/` را در `App/docs/design-system/` بگذارید و فایل‌های قبلی را جایگزین کنید. پوشه `fonts/` را کپی نکنید؛ آن پوشه فقط برای نرم‌افزارهای طراحی و چاپ است. فایل‌های `GAPS.md` و `PACKAGE-README.md` که فقط در ریپو هستند را پاک نکنید.
2. **شروع Claude Code:** Claude Code را در ریشه `App` باز کنید و متن `START-PROMPT-FOR-CLAUDE-CODE.md` را، از زیر خط به بعد، برایش بفرستید. Claude Code باید با همان حساب Claude این پروژه کار کند تا لینک‌های زیر برایش باز شوند.
3. **پیاده‌سازی:** Claude Code به ترتیب `HANDOFF-FOR-CLAUDE-CODE.md` کار می‌کند و قاعده‌های اجباری `CLAUDE-CODE-DESIGN-SYSTEM-RULES.md` را رعایت می‌کند: یک زبان بصری، فقط فونت IRANSansX، فقط فایل‌های لوگو و برند بسته، ۷۸ عکس تأییدشده، و وفاداری نزدیک به صفحه‌های کلیدی.
4. **QA نهایی (اجباری):** وقتی کار تمام شد، Claude Code دستور `QA-FINAL-RECONCILIATION.md` را کامل اجرا می‌کند:
   - کل سیستم طراحی و همه صفحه‌های کلیدی را با کد تطبیق می‌دهد.
   - هر چه جا افتاده را از روی سیستم طراحی می‌سازد.
   - گزارش `docs/qa/design-system/QA-REPORT.md` را می‌نویسد.

   تا وقتی `qa/ds-audit.mjs` خطای FAIL دارد، کار تمام‌شده نیست.

- صفحه‌های کلیدی K1 تا K19 در دو اندازه و بوردهای برند: https://claude.ai/artifact/85Z6AZDVJRPzhWvYAEkY92

این دو لینک با همان حساب Claude پروژه باز می‌شوند. همان محتوا، به‌صورت آفلاین، داخل همین فایل هم هست. در بوم صفحه‌های کلیدی فقط صفحه‌های «۱۸ صفحه کلیدی × ۲ اندازه» و «برند و آیکون اپ» تأییدشده‌اند. گزینه‌ها و واریانت‌های قبلی خانه فقط برای سابقه نگه داشته شده‌اند.
