# آمادگی اتصال‌های بیرونی و داده واقعی

وضعیت‌ها طبق `ARCHITECTURE_BASELINE.md`: `NOT_CONFIGURED` → `LOCAL_TEST` → `SANDBOX_VERIFIED` → `LIVE_VERIFIED`. هیچ ارائه‌دهنده، endpoint، credential یا تعرفه‌ای اختراع نشده است.

**قاعده الزامی:** آداپتور جعلی/محلی هرگز در `APP_ENV=production` فعال نمی‌شود. راه‌اندازی برنامه در حالت production با هر آداپتور `NOT_CONFIGURED` که برای مسیر فعال لازم است، **fail-fast** می‌کند و پیام مشخص می‌دهد؛ به‌جای اینکه بی‌صدا داده ساختگی برگرداند.

## ۱. محیط اجرای تأییدشده

بررسی واقعی در همین ماشین (۲۰۲۶-۰۹-۰۲):

```
node   v24.13.1
npm    11.8.0
pnpm   11.5.2
git    2.41.0.windows.3
docker 29.6.2
psql   not available (کلاینت محلی نصب نیست؛ سرور از docker تأمین می‌شود)
npm ping → PONG (registry.npmjs.org در دسترس)
```

## ۳. داده واقعی که وجود ندارد و ساخته نمی‌شود

این‌ها «فقدان داده» هستند، نه «ابهام فنی». مسیر ورودشان ساخته می‌شود؛ مقدارشان اختراع نمی‌شود.

| داده | مرجع | وضعیت |
|---|---|---|
| تعرفه عضویت | §۷، §۲۲ | مقدار مبنای مستند ۳۰۰٬۰۰۰ تومان به‌عنوان **seed تنظیمات** وارد می‌شود و از پنل مدیریت قابل تغییر است. در کد ثابت نمی‌شود. |
| تعرفه برگه ثبتی، شجره‌نامه، مجوز جفت‌گیری، ثبت کنل، Puppy Card | §۲۱.۴، §۲۲ | **تعیین‌نشده.** رکورد تنظیم با مقدار خالی ساخته می‌شود؛ UI «تعیین‌نشده» نشان می‌دهد و مسیر پرداخت آن قلم تا ورود مقدار باز نمی‌شود. عدد ساختگی درج نمی‌شود. |
| مهلت مراجعه | D15، §۱۱.۴ | مقدار اولیه **۲۱ روز** به‌عنوان seed تنظیمات (تصمیم قطعی مالک محصول). هاردکد نمی‌شود. |
| اطلاعات مرکز ژنتیک ثابت: نام، تماس، شماره حساب/کارت | D07، §۲۱.۴ | **تعیین‌نشده.** بدون این داده، مرحله «پرداخت مستقیم به مرکز و آپلود فیش» مبلغ/مقصد واقعی ندارد. رکورد تنظیم ساخته می‌شود؛ حساب جعلی درج نمی‌شود. |
| فهرست صادرکنندگان شجره‌نامه موردتأیید انجمن | D14، §۹.۴، §۲۹.۲ | **تعیین‌نشده.** جدول مرجع + CRUD در پنل انجمن ساخته می‌شود؛ نام صادرکننده ساختگی وارد نمی‌شود. فهرست خالی، مسیر بررسی را حذف نمی‌کند. |
| فهرست نژادها (فارسی/انگلیسی) | §۱۵.۲، §۹.۱ | داده مرجع. پروتوتایپ ۱۰ نژاد واقعی نشان می‌دهد (ژرمن شپرد، لابرادور رتریور، گلدن رتریور، هاسکی سیبری، روتوایلر، دوبرمن پینشر، پودل، بیگل، شیتزو، سگ سرابی). همان‌ها به‌عنوان seed اولیه وارد و از پنل مدیریت قابل گسترش می‌شوند. |
| مقادیر OTP: TTL، سقف تلاش، مدت قفل | §۶.۱، §۲۹.۲ | **تعیین‌نشده به‌عنوان سیاست مصوب.** مقدار پیش‌فرض فنی محافظه‌کارانه در تنظیمات seed می‌شود و در `DECISIONS.md` به‌عنوان انتخاب فنی قابل بازگشت ثبت می‌شود، نه به‌عنوان سیاست تأییدشده مالک محصول. |

| ارائه‌دهنده و تعرفه پست | D17، §۱۴.۶ | **خارج از دامنه فاز یک.** فقط ثبت درخواست؛ نه تعرفه، نه رهگیری، نه SLA. |

## ۴. اثر بر وضعیت مراحل بعدی

- PROMPT-005 (پرداخت/عضویت) با آداپتور sandbox و verify سمت سرور قابل تکمیل کد است، ولی `integrations` آن تا اتصال درگاه واقعی `NOT_CONFIGURED` می‌ماند و `production: NOT_READY` است.
- PROMPT-010 (فیش ژنتیک) بدون داده حساب مرکز، مسیر آپلود/بررسی فیش را کامل می‌سازد ولی مقصد پرداخت را «تعیین‌نشده» نشان می‌دهد.
- PROMPT-006/PROMPT-018 (بررسی شجره‌نامه خارجی) بدون فهرست صادرکنندگان، صف و گردش را کامل می‌سازد و فهرست را خالی نگه می‌دارد.
- PROMPT-003 (DS) به دلیل یافته بخش ۳ سند `reference-access.md` توکن‌ها را در کد تعریف می‌کند؛ `visual: UNVERIFIED` تا تطبیق صفحه‌به‌صفحه.

هیچ‌کدام از این موارد اجرای بخش‌های مستقل را متوقف نمی‌کنند.
