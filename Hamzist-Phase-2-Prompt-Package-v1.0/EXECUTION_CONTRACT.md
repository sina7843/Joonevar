# قرارداد اجرا

1. پرامپت‌ها به‌ترتیب اجرا شوند.
2. قبل از تغییر، وضعیت واقعی و Migrationهای اعمال‌شده خوانده شود.
3. تغییر خارج از دامنه با Decision ثبت‌شده انجام شود.
4. هر مرحله گزارش فایل، داده، تست، ریسک و Known Gap داشته باشد.
5. داده تولیدی یا قیمت ساختگی وارد Production نشود.
6. تغییرات کاربر و Commitهای نامرتبط حفظ شوند.
7. Completion فقط بعد از Build/Typecheck/Test مرتبط ثبت شود.
