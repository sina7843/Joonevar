# PROMPT-011 — بسته‌های تبلیغاتی

## هدف
پلن پایه رایگان و بسته‌های ویژه/حرفه‌ای ۳۰، ۹۰ و ۳۶۵ روزه را با قیمت تنظیم‌پذیر، پرداخت، شروع/انقضا، تمدید، ظرفیت جایگاه و Audit بساز.

## منابع الزامی
- `Requirements-Phase-2.md`
- `PRODUCT_DECISIONS.md`
- `ARCHITECTURE_BASELINE.md`
- خروجی و گزارش پرامپت‌های قبلی
- کد واقعی شاخه جاری؛ حدس بر سند و نمونه مقدم نیست

## قواعد قطعی
- فارسی و RTL واقعی؛ فقط کد و شناسه‌ها LTR.
- داده عمومی جدید با موجودیت‌های فاز یک موازی‌سازی نشود.
- Verification، Trusted و Advertising مستقل بمانند.
- هیچ تعرفه، زمان، مجوز یا ادعای پزشکی ساختگی اضافه نشود.
- تغییر حساس، Actor، زمان، مقدار قبلی/جدید و دلیل داشته باشد.
- هیچ قابلیت خارج از این پرامپت بدون ثبت Decision اضافه نشود.

## کار اجرایی
1. ابتدا وضعیت واقعی کد و وابستگی‌های مرتبط را گزارش کن.
2. Schema، Migration، Service، Route، UI و Permission لازم را کامل کن.
3. حالت‌های loading، empty، error، forbidden، duplicate و archived را پوشش بده.
4. تست دامنه، دسترسی و مرورگر اضافه کن.
5. از مسیرهای موجود فاز یک تست رگرسیون بگیر.

## معیار پذیرش
- رفتار اصلی end-to-end با داده واقعی قابل اجرا باشد.
- تغییر URL یا شناسه، دسترسی غیرمجاز ایجاد نکند.
- UI موبایل و دسکتاپ، فارسی و قابل استفاده باشد.
- Build، typecheck و تست‌های مرتبط موفق باشند.
- گزارش شواهد شامل فایل‌های تغییرکرده، Migrationها، تست‌ها و Known Gaps ثبت شود.
