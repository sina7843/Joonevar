# بسته اجرای فاز دوم همزیست

این بسته برای اجرای مرحله‌ای بخش عمومی همزیست ساخته شده است. ترتیب پرامپت‌ها الزامی است؛ هر مرحله باید وضعیت واقعی کد را بخواند، تغییر را پیاده‌سازی کند، تست بگیرد و گزارش شواهد بنویسد.

## ترتیب شروع
1. `Requirements-Phase-2.md` و `PRODUCT_DECISIONS.md` را کامل بخوان.
2. `ARCHITECTURE_BASELINE.md` و `ACCEPTANCE_MATRIX.md` را بررسی کن.
3. پرامپت‌های `001` تا `020` را به‌ترتیب اجرا کن.
4. بدون شواهد تست، هیچ مرحله‌ای کامل علامت نخورد.

## اصل عدم تعارض
فاز دوم روی Phase 1 ساخته می‌شود. هیچ Route، نقش، داده یا گردش‌کار تثبیت‌شده فاز یک نباید برای راحتی بخش عمومی بازتعریف یا دور زده شود.
