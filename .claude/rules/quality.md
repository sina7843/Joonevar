# Evidence and decisions

A screenshot is not end-to-end success. An API test is not visual fidelity. A mocked gateway is not live verification. Record actual commands and results, including skips/limits. Mandatory missing checks block completion; independent work may continue without falsifying status. Document and report autonomous choices in DECISIONS.md; do not convert missing real facts into fabricated defaults. Avoid excessive test duplication; focus on persistence, payment, authorization and versioning risks and source acceptance.
