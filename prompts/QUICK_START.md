# شروع پرامپت‌ها

برای کل پروژه: START_CLAUDE.md یا RUNNER.cmd start.
برای یک مرحله: RUNNER.cmd start-step N.
ادامه: همان دستور شروع؛ پیشرفت در مخزن حفظ می‌شود.

کاربر نباید بعد از هر مرحله done بزند. کلاد پس از اجرای موفق، گزارش دارای شاهد را کامیت می‌کند، `node tools/runner.mjs complete N --commit HEAD` می‌زند و سپس وضعیت پیشرفت را کامیت می‌کند. در گزارش، تصمیم‌ها و هر دو هش می‌آید.

اگر یک Gate الزامی قابل اجرا نبود، گزارش PARTIAL/BLOCKED و checkpoint ایجاد می‌شود؛ ابزار برای عبور ظاهری از آن نیست. مستقل بودن کارهای دیگر اجازه می‌دهد آن‌ها تکمیل شوند، ولی مرحله ناقص به COMPLETE تغییر نمی‌کند.
